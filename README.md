# Flight Simulator Prototype (Unity 6)

A foundational 3D project focused on smooth movement and environment interaction in Unity 6.

## Key Features
* **Flight Controller:** Custom C# script handling 3D movement and rotation.
* **Third-Person Camera:** Implemented a follow-camera system for smooth player tracking.
* **Environment:** Designed a 3D mountain landscape using Unity’s Terrain tools.

## How to Play
1. Clone the repository.
2. Open in **Unity 6**.
3. Press Play, Use [ZQSD] to move, hold SHIFT to jump while on the ground, hold SHIFT in the air to Air Boost, hold Z to glide and S to slow down.
